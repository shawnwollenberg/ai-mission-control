# Mission Agent release history

- **0.8.0** is the KMS-signed governed Consensus Plan release for the Runtime-v6
  control plane. Its initial production onboarding is limited to a
  non-destructive planning/read-only Consensus Plan; implementation authority
  remains separately gated. It is not substituted into the legacy guided
  first-mission channel, whose task envelope does not carry an exact model.
- **0.7.2** remains the signed general guided-onboarding and rollback release.
  Its artifact and Manifest v3 bundle remain unchanged.

- **0.6.8** is a preserved historical signed release. Its artifact and v1
  manifest remain unchanged.
- **0.6.9** is an unsigned, unpublished internal repository-identity candidate.
  It is retained as historical evidence and is not trusted for installation.
- **0.7.0** is the first unsigned Release Authority v2 and manifest v2 release
  candidate. It is blocked from signing, publication, onboarding, installation,
  and deployment until the planned public key is introduced and activated
  through an authenticated Mission Control release.
