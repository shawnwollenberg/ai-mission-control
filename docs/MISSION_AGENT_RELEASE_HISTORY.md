# Mission Agent release history

- **0.6.8** is the active signed production release. Its artifact and v1
  manifest remain unchanged.
- **0.6.9** is an unsigned, unpublished internal repository-identity candidate.
  It is retained as historical evidence and is not trusted for installation.
- **0.7.0** is the first unsigned Release Authority v2 and manifest v2 release
  candidate. It is blocked from signing, publication, onboarding, installation,
  and deployment until the planned public key is introduced and activated
  through an authenticated Mission Control release.
