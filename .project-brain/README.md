# Project Brain

This directory is the repository's Git-versioned operational memory.

- Markdown is for human-readable state, architecture, decisions, issues, and playbooks.
- YAML is for validated profiles, context packs, mission results, lessons, and reviews.
- New lessons begin in `lessons/proposed/` and require independent review before confirmation.
- Evidence must reference inspectable repository files, commits, commands, tests, or artifacts.
- Secrets, raw transcripts, and hidden reasoning do not belong here.

Use the templates and schemas in this directory. Keep current state concise and encode durable lessons in executable controls when practical.
